# 微信 3.x 版本过低修复

## 📖 项目简介
本项目旨在解决微信 3.x 版本在部分 Windows 系统上提示“版本过低”的问题，**无需升级微信**即可修复。

## 🛠️ 解决方法
通过修改注册表的兼容性设置，让 Windows 以特定兼容模式启动微信，从而绕过版本检测。
1.  下载本仓库中的 `fix_wechat_version.reg` 文件。
2.  **重要：** 用记事本打开该文件，将里面的路径修改为你自己的微信安装路径（例如 `C:\\Program Files (x86)\\Tencent\\WeChat\\WeChat.exe`）。
3.  保存文件后，双击运行，按照提示导入注册表即可。
4.  重新打开微信，问题应该已经解决。
> **注意**：请确保你的微信安装路径与文件中的路径一致，否则修复无效。

## ⚠️ 兼容性说明
本项目提供的方法经实操对 **Windows系统** 上的 **3.9.12.56** 版本可行，其他系统和版本尚未尝试。

## ⚠️ 风险提示
- 本方法通过修改系统注册表实现，请自行评估风险。
- 如果未来微信更新导致此方法失效，请删除对应的注册表项。
- 使用非官方方式绕过版本检测，理论上存在账号风险，请谨慎使用。
